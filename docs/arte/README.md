## Shaders do cenário

- `shaders/wall.gdshader`: paredes com rodapé, barra azul escura embaixo, frisos
  de painel, manchas de sujeira e sombra perto do chão e do teto.
- `shaders/floor.gdshader`: piso de lajotas com variação por peça, rejunte,
  manchas úmidas brilhantes e sujeira. Com `tile = 0`, vira grama sem grade.
- `shaders/plush.gdshader`: também usado na copa das árvores, nas cercas vivas,
  na casca do tronco e no tecido das becas.

Os modelos 3D usados no jogo ficam em `models/`. Esta pasta é só para referência
e não é importada pelo Godot.
